# Сайт урока «Налоговая отчётность» · Команда 8

## Что на сайте
| Раздел | Адрес | Для кого |
|---|---|---|
| 5 тем со слайдами | `#t1` … `#t5` | все |
| Работа на закрепление — 10 вопросов, 10 баллов, объяснение к каждому ответу | `#practice` | студенты, после тем |
| Exit-ticket — финальная проверка, 20 баллов | `#work` | студенты, в конце |
| Панель ведущих — ход игры, вывод кейса на экран, результаты (PIN) | `#admin` | команда 8 |
| Экран для проектора | `#screen` | проектор |

## Файлы
```
public/            ← это и есть сайт (его нужно выложить на хостинг)
  index.html       темы, Exit-ticket
  extra.js         закрепление, панель ведущих, экран
  cases.js         все задания: кейсы, доп. кейсы, устные вопросы, закрепление
  db.js            связь с Supabase
  config.js        адрес и ключ Supabase (заполнить!)
supabase/schema.sql  база данных — выполнить один раз в Supabase
server.js          локальный сервер для проверки на своём компьютере (не обязателен)
```

## Где всё работает
- **Сайт:** https://fifaas.github.io/nalog/ — GitHub Pages, ветка `gh-pages` (содержимое папки `public`).
- **База:** Supabase, проект `nalog` (организация FifaAs). Схема — `supabase/schema.sql`, уже выполнена.
- **PIN ведущих** хранится в базе. Сменить: Supabase → SQL Editor →
  ```sql
  update public.app_secret set pin = 'новый PIN' where id = 1;
  ```
- Бесплатный проект Supabase засыпает после 7 дней без активности — перед занятием зайдите
  в панель Supabase и при необходимости нажмите **Restore project**.

## Как выложить изменения
После правок в папке `public`:
```
git add -A
git commit -m "что изменилось"
git push origin main
git branch -f gh-pages $(git subtree split --prefix public)
git push origin gh-pages
```
Через 1–2 минуты изменения появятся на сайте.

## Как проверить на своём компьютере
```
node server.js
```
и откройте http://localhost:3000. Без заполненного `config.js` всё работает, но данные хранятся
только в этом браузере, а экран обновляется, если открыт на этом же компьютере.

## Во время занятия
- **Проектор:** откройте `ссылка-на-сайт/#screen` на ноутбуке у проектора.
- **Ведущие:** `#admin` → PIN.
  - вкладка «Экран» — вывести любой кейс, доп. кейс или устный вопрос, показать ответ, запустить таймер;
  - вкладка «Ход игры» — команды и роли, отметки ✓/✗ по кейсу, тайные ходы, доп. кейс и вопросы Аудиторов. Очки считаются сами по правилам игры;
  - вкладка «Результаты» — закрепление и Exit-ticket всех студентов, копирование в Excel, проверка кода.
- Ход игры удобнее вести с одного устройства (Протоколист): сохраняется автоматически.

## Игра
Правила — `pravila-igry.html`. Сейчас игра идёт в аудитории вживую, а сайт помогает ведущим:
выводит кейсы на экран и считает очки. Автоматическая версия с телефонами команд (`public/game.js`) отложена.
